# Provenance

This public-facing repository keeps the provenance material needed to verify the accepted scientific implementation without publishing the full curator working ledger.

- `CANONICAL_CODE_HASHES.csv` records hashes of the frozen accepted W09 scientific code.
- `CLEANING_CHANGELOG.md` documents behavior-preserving repository curation.

The complete forensic inventory and disposition ledger are retained in the separate curator release package used for pre-publication review.
